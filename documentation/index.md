# Agent-Harmony Python

Python bindings for the [Agent-Harmony C++20 library](https://github.com/Tosiekdev/Agent-Harmony).

!!! note "v0.0.0 — Repository foundation"

    This release establishes packaging, a native extension, tests, and development
    infrastructure. No agent, model, scheduling, spatial, or visualization APIs
    are exposed yet.

Start with [installation](getting-started/installation.md), verify the
[package import](getting-started/quickstart.md), and inspect the
[API reference](reference/index.md). [Examples](examples.md) contain only
metadata checks. [Release notes](release-notes.md) describe this milestone.

The Python interface, native bindings, and pinned upstream sources remain
separate. Future bindings will build on existing upstream capabilities.
