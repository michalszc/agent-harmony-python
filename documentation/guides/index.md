# Development guides

Before implementing functionality, inspect the upstream library for the required
method. Bind existing behavior where possible and avoid speculative wrapper APIs.

The [contribution guide](https://github.com/michalszc/agent-harmony-python/blob/master/CONTRIBUTING.md)
covers environment setup, native rebuilds, Make checks, submodule updates,
packaging validation, and the retained CI/CD/release workflow.

User simulation guides will be added with implemented bindings.
