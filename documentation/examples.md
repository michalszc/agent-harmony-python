# Examples

- [Python example](https://github.com/michalszc/agent-harmony-python/blob/master/examples/basic_usage.py):
  import the installed package and print its version; run with `make examples-check`.
- [Basic usage notebook](https://github.com/michalszc/agent-harmony-python/blob/master/examples/basic_usage.ipynb):
  the same metadata check with saved output; validate with `make notebooks-check`.

Notebook validation does not execute cells or install packages. No example claims
Agent-Harmony functionality that has not been bound yet.
